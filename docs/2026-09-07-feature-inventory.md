# 功能点全景与风险清单（2026-09-07 归档）

> 详版模块地图见 CLAUDE.md（按日期增量）；本文是面向使用者的功能全景 + 已知坑/优化点快照。

## 一、五类项目入口 → 同一终点 merged

| 入口 | 特点 | 关键参数（创建时可定） |
|---|---|---|
| 📎 上传小说 | LLM 分析→拆分镜全链 | 画风/字幕/兆像素/倍速/质量/段时长/总时长 |
| 🎨 主题生成 | 两步流（预览正文→确认） | 同上 |
| 🖼 漫画导入·动态漫 | fl2v 翻页，画风跟随原页，快 | 模式/时长（画风不消费，明示） |
| 🖼 漫画导入·漫改电影 | ref2va，画风转换+角色参考图 | 同上 + 画风=转换目标 |

## 二、生产线核心能力

- **autopilot 一键出片**：3s 巡检幂等续跑；失败守卫（批次失败等手动/单镜失败跳过推进）；跨类型在飞感知；merged 自动关
- **时长体系**：段时长 0=智能估（小说 LLM 字数基准 / 漫画读图后对白重估，同公式 ⌈字数/4⌉+0.6×(句数-1) 钳 4~15）；对白镜成片段长=配音+0.5s 收口
- **音色配音**：分析期自动生成绑定（qwen_tts 克隆）；ref2va 注入样本保 H3 原声口型（h3_native_voice）；fl2v 系克隆/Edge-TTS 整轨替换；多说话人 Edge 按性别
- **提示词五模式**（A~E，默认 E 英文控制式）+ heal 自愈 + 说话人净化（脚手架短语/动词后缀拒收、包含式归一）
- **渲染**：ref2va/fl2v/t2v/快车道 director（分批+接力+段级音色）；版本 video_v{N}；断点对账 reattach
- **合成**：FFmpeg concat/xfade、TTS 替换+收口、SRT 生成、字幕烧录（项目级开关）、混音 director_mix
- **运维**：温和停止、失败重发、强制重读、purge 清理、日志 logbus、快照审计、🧹 记录清理

## 三、已知坑（2026-09-07 快照）

1. **start-prod 无热重载**：改代码必须重启；版本探针=右上角按钮文字（「创建项目」=新代码）。本周三次事故均源于没重启
2. **浏览器缓存**：前端更新后需 Ctrl+F5 强刷（no-cache 只保再验证）
3. **估时不追溯**：只作用于本次生成提示词的镜；存量镜要 强制重读 或手改
4. **describe_shots 不在重启重排白名单**：重启杀在跑读图 job 后需手动重触发
5. **Windows 路径转义**：ffmpeg concat/滤镜里 `\` 是转义符——已修两处（字幕滤镜、TTS 合并清单），新 subprocess 场景须 as_posix + check=True
6. **Edge-TTS 依赖网络**：逐句失败有重试缺；克隆音色优先可降低依赖
7. **有声书校正后需重拆**：写回有 warn 提示；重拆后校正文本与音频段的机械对齐可能局部失配（要瞄时长）
8. **无对白镜 H3 杂音**：mute_quiet_shots 可封（代价丢环境声）
9. **manga7 存量 ledger 仍含旧垃圾对白**：重新合成前应 🗑清理+🔄强制重读，否则垃圾台词会被 TTS 念出

## 四、优化点（按价值排序）

1. **Edge-TTS 逐句重试 + 并发生成**（配音 15 分钟 → 数分钟，抗网络抖动）
2. **渲染模式项目级字段**（现在建后才能批量切，创建高级区缺位）
3. **快车道 director_mix 补 B3 收口**（帧数轴重切，当前主链逐镜已覆盖）
4. **强制重读支持「只重估时不重读」**（免烧 VLM 只刷时长）
5. **合成产物缓存**：重复合成时未变镜段复用（现全链重编码）
6. **说话人净化词表外置**（settings 可编辑，免发版加词）
