## 二、网络检索结论（2025-09 ~ 2026-07）

1. **Qwen-Edit-2511 支持多图输入**（继承 2509 的 1-3 图拼接编辑）：官方增强点正是「**多人合照一致性**（两张人物图融合为一张）+ 缓解图像漂移 + 角色一致性显著提升」。提示词范式：`将图1的人物与图2的人物放在{场景}` 按图号引用。
2. **FLUX.2 Klein 4B**（2026-01 发布，Apache 2.0）：多参考最多 3 图（FluxKlein conditioning 节点，需尺寸对齐）；评测共识——**速度/显存碾压**、写实美学强，但**身份保持弱于 Qwen Edit**（Qwen 是人脸/角色一致性的 go-to）。
3. Qwen-Edit 多图同时原生吃 ControlNet 条件（keypoint 姿态/草图）——**页间构图连续性**的现成控制面。
4. 复杂多图重摆姿任务两个模型都会翻车（arena 判例）——多角色+特定姿态同时控制别指望一步到位，分步（先合成场景再控姿态）。

## 四、推荐路线（渐进、全部零下载）

1. **v1.1（立即）**：二期模板升级 2511 多图——`TextEncodeQwenImageEdit` 多图输入（2511 原生）：单角色=base 主图；双角色=图1+图2 官方多人融合；挂 Lightning 4 步 LoRA（8→4 步，速度约翻倍）。双角色从「文字锚」升级为真参考注入（决策表 3 的完整兑现）。
2. **v1.2（场景一致性）**：场景资产也生成参考图（genref 场景道），`person + scene` 组合入槽——场景跨页视觉一致（不只文字）。
3. **v1.3（页间构图连续性，可选）**：拆解产出「姿态参考」（LLM 给动作描述→keypoint 图或上页构图作参考第 3 槽）——分镜构图可控。复杂姿态别一步到位，分步合成。
4. **备选道**：追求极限速度/批量草稿时用 FLUX.2 Klein 4B 建第二模板（template_map 可切换）——英文提示词流。
