📁 项目类型与操作流程

🎬 视频项目（终态：合成成片 epNNN.mp4）

📎 上传小说

① 上传 txt 章节文件
② 选画风 / 画幅 / 时长参数
─────────
③ LLM 分析 → 提取角色/场景/道具
④ 生成参考图（主图+三视图）
⑤ ✓ 确认资产（门1）
⑥ 拆分镜 + 生成提示词
⑦ ✓ 确认分镜（门2）
⑧ 逐镜渲染 → 合成成片
💡 支持多章节（第X章切分）和分镜数指定

🎧 有声书导入

① 上传音频（mp3/wav/m4a，≤200MB）
② 自动 ASR 转写回填正文（等 job 完成）
─────────
③ 之后的流程与小说完全相同（分析→参考图→分镜…）
④ 分镜时长 = 音频实测时长（自动，无需设置）
⑤ 逐镜渲染 → 合成成片
💡 需装 asr extra；转写期间全队列串行（长书先切分）；转写未完成点一键出片会被拦

🎨 主题生成

① 选预设主题（或自建）
② 可加补充描述 / 主角名 / 字数
③ ✨ 生成正文（1-3分钟）
④ 预览 / 编辑 → ✔ 确认创建
─────────
⑤ 后续流程同小说（分析→渲染）
💡 内置短剧结构规范：黄金3秒钩子 / 情绪流变 / 断章卡点 / 对白语速公式

🖼 漫画导入

📖 动态漫模式（快）
① 导入漫画页（自动排序+压缩）
② 👁 读图生成提示词（VLM 看图）
③ ✓ 确认 → fl2v 翻页渲染
──── ~100s/镜 ────
🎬 漫改电影模式（慢）
① 导入 + 选「漫改电影」
② 🎭 提取角色（可选，多次只留最新）
③ 生成参考图 → 👁 读图提示词
④ ✓ 确认 → ref2va 角色动画渲染
──── ~3-5min/镜 ────
💡 漫改自动画风转换（二次元↔真人）+ 多角色识别

📖 漫画项目（终态：漫画就绪，页面即交付物，无视频链）

📖 小说转漫画成书

三种数据源（任选其一）
📎 文本小说——上传 .txt 正文（UTF-8）
🎧 有声小说——音频自动转写回填（需 asr extra）
🎨 主题生成——选主题 → LLM 生成正文
─────────
② LLM 分析角色（拆解上下文用）→ 拆成漫画页（每镜=一页：场景+人物+对白；可指定页数）
③ 🚀 一键出片：逐页 t2i 出图 →「漫画就绪」自动停
④ 「漫画页」页签浏览 · 缺页「🖼 生成缺失页」补 · 📄 导出 PDF / 📜 导出长图
💡 对白呈现三式：气泡（透明度/字色/字号可调）/底部字幕条/不呈现；尺寸 10 档（512 小尺寸约 4 倍快）；质量档=采样步数（快速8·标准12·高质量20）

⚡ 核心功能

🚀
一键出片
全自动：分析→参考图→拆镜→提示词→渲染→配音→字幕→合成
🚄
整段快车道
导演台批量渲染（分批 latent 连贯 + 批间首帧接力 + 整片混音）
🎵
角色音色
15 预设+自定义音色（克隆上传）→ 渲染注入 H3 原生配音（口型同步）；LLM 分析自动匹配，可手动改绑
🎙
配音+字幕（视频项目）
未绑音色走 Edge-TTS 按性别；绑了音色保 H3 原声；SRT 字幕烧录
📖
漫画成书
小说直出漫画：拆页→逐页 t2i→气泡/字幕条对白→PDF/长图导出（页面即交付物）
🖱
分镜框选
分镜导航数字条按住左键扫框批量勾选（Shift 追加）→ 批量无效/生效/删除
🔍
媒体查看器
点首尾帧/视频全尺寸弹窗，← → 连续翻页浏览各镜媒体
👁
VLM 读图
视觉模型看漫画页 → 生成动画提示词 + 提取对白（逐镜/批量）
⏹
停止任务
项目级一键停止（取消待跑 + ComfyUI 清队中断在跑的）
🔄
分镜控制
批量 无效/生效/删除 · 无效镜不进渲染和合成 · 分镜数指定

⚙️ 设置速查

🤖 LLM 设置：本地服务商切换（Ollama/LM Studio/自定义，预设地址一键填）+ 线上 API
🔀 任务路由：每个任务可独立选服务商/模型（长文本建议对话模型）
🎬 工作流：模板映射（主图/三视图/视频/导演台）+ 模型切换 + 性能开关
🎧 ASR 引擎：faster-whisper（本地直连，带时间戳）｜ ComfyUI Qwen3-ASR（中文更准，context 热词=内容主题；长音频自动分块防输出不全）
📚 预设主题：主题模板管理（导入/编辑/删除）
🎵 音色库：15 预设批量生成（⟳ 可重生成+试听）· 全局/项目级自定义上传（裁剪→克隆→试听→确认入库）· 项目页「🎭 角色配音」逐角色：分析自动绑（预设优先）→试听/换绑→声线描述生成专属→⤴晋升全局复用
💡 提示：操作日志在项目详情页底部实时滚动 · 队列状态在工具栏（运行/排队/失败）· 修改 Python 代码后需重启服务
🖱 操作技巧：点顶部「漫剧工坊」回首页 · 分镜导航条按住左键扫框=批量选择（Shift 追加）· 点分镜首尾帧/视频=全尺寸查看器（← → 翻页）
