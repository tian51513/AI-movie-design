打算做一个小说转漫剧的项目，大体流程是：配置好本地comfyUI、本地ollama调用API及预设模型、资产仓库、一些预设工作流【文生图、图生图、图生视频、文生视频、首尾帧生视频、全能参考生视频等，可选】等一系列准备工作 → 导入小说文本，漫剧命名创建对应的子项目，资产仓库子目录 → LLM 分析有哪些角色哪些必要的场景哪些必要的道具，分析人物的外貌描述已固化人物【本地ollama的API或者线上API】这些内容也可以放到子项目的资产仓库中 → 通过 ComfyUI API 调用本地 ComfyUI文生图工作流，分别为每个角色每个场景创建对应的多视角参考图，角色参考图、场景参考图，全局复用，放到对应资产目录中，用户可以针对个别参考图再生成 → LLM 拆分小说文本成分镜，分镜绑定对应出场角色资产、场景资产，分镜逐个串行调用自定义 ComfyUI 工作流：可以分别映射文生图、IP-Adapter 角色参考、首尾帧 I2V、MiniMax H3 Ref2VA、LTX2.3 任意视频工作流，把资产图片注入对应节点  → 一段跑完再下一段，可以有一些避免爆显存的措施以保证整个生成流程的正常进行。工作流配置的时候可以预设不同类型的，比如：生成人物、生成场景、生成道具、普通文生视频、首尾帧工作流、参考图视频工作流。做到任务队列、项目隔离，分析下自带 FFmpeg 合并分镜视频有没有必要及如何实现。工作流可以先分析下这个目录下的工作流：E:\Comfy-Desktop\ComfyUI-Installs\anime-gc\ComfyUI\user\default\workflows。本地ollamaAPI地址：http://127.0.0.1:11434/api。
